# COMPOUND
  It's back.

  Now with memory pool to reclaim allocated resources,
  **automatically**.

## Building
  ```shell
  cmake .
  make
  ```

## Output
  - Executable
    - `out/bin/CompoundTest`
    - `out/bin/CompoundTest.exe`

  - Library
    - `out/lib/libcompound.so`
    - `out/lib/libcompound.dylib`
    - `out/lib/libcompound.dll`

## Spec. Notes
  Even though this project follows *general* C99 standard,
  it does not use VLA, or, Variable Length Array in any object definition.
